# 视觉与交互设计

版本：2.1｜日期：2026-10-01｜已同步黑色星空、流星、首页交互与紧凑布局

## 1. 视觉方向

页面采用接近漆黑的星空和细小星点，暖金色强调与浅色正文。星点在完全淡出后随机更换位置，切换页面不重启；260 个星点随机分布，渐亮、闪烁、淡出到完全透明，然后在新的随机位置再次出现；大小、亮度和暖冷色在消失时重新生成，各自周期不变，避免位置跳变时被看见。多数较暗，少量带暖色；三条流星轮流划过并留下短暂淡尾迹。减少动态效果时星点静止、流星关闭。全站面板与表单同步为暗色，牌义弹层采用半透明深色毛玻璃、28 px 模糊与细亮边缘，背景的牌面色彩自然透入；固定标题栏背景延伸至弹层外框，由外框裁切圆角，关闭按钮与文字保留安全内边距；标题栏使用 95% 不透明的深色底与 20 px 模糊，避免滚动正文透出干扰阅读，减少透明度及增强对比度时使用实色回退。保留原始牌面的复古插图和衬线字体。牌背为深紫黑底、亮粉与淡金线描的旋转对称沙漏、水晶、植物与细边框，素材见 `design/`。

| 元素 | 初始设计值 |
|---|---|
| 页面底色 | #020305，近黑底色与细小星点 |
| 内容面板 | 首页半透明 #0D1014，其余面板 #11192C，释义弹层 #131B2B（65% 不透明），标题栏 #101725（95% 不透明） |
| 主要正文 | #EEF0FA |
| 辅助正文 | #ABB3CB |
| 强调色 | #D7C097，暖金 |
| 次强调色 | 蓝紫透光与浅色边缘高光 |
| 边线 | 半透明 #BEC9F1 |
| 圆角 | 内容面板 16 px；顶部 28 px；手机菜单 30 px |
| 纹理 | 固定星空、闪烁星点与间歇流星，不遮挡交互 |
| 标题字体 | 支持中文的衬线字体，实施时核查字体来源 |
| 正文字体 | 易读中文字体，本地打包必要字形或使用系统回退 |

星空由 CSS 与淡出后随机换位的星点生成，无外部图片或网络依赖。字号、透明度和颜色通过桌面及手机截图检查。

顶部悬浮导航和手机底部浮岛采用低透明底色、7 px 背景模糊、155% 饱和度与上下边缘高光，星空及卡牌颜色可以透出。菜单共享一个滑动高光胶囊；屏幕变化后重新定位。浏览器不支持模糊或用户要求减少透明度时采用实色回退，增强对比度偏好时加深底色。

按钮按压目标 scale(0.96)，110 ms 压缩并增加深度内阴影；松开从当前实际缩放值采样 560 ms 阻尼弹簧，轻微超调后回到 1。快速再按时取消前一段动画并从当前位置继续。指针取消、窗口失焦会清除按压状态；键盘 Enter / 空格同样可用。圆弧牌仅压缩图像以保留狭窄外角的点击范围，原旋转与升起不受影响。减少动态效果时保留即时压缩，关闭回弹。

## 2. 页面与路由

| 页面 | 建议路径 | 主要功能 |
|---|---|---|
| 首页 | / | 模式选择、今日状态、查询入口 |
| 抽牌 | /draw | 模式设置、选牌、翻牌与结果；模式保存在会话 |
| 图鉴 | /cards | 全 78 张浏览、搜索、分类 |
| 卡牌详情 | /cards/:id | 可直接打开的卡牌详情 |
| 历史 | /history | 时间倒序、筛选、删除 |
| 历史详情 | /history/:id | 结果、问题、笔记、分享 |
| 设置 | /settings | 逆位、声音、离线资源、本地数据管理 |

桌面用顶栏导航；手机用精简顶栏和底部主要入口。全局查询由顶栏或固定查询按钮打开，不要求跳到图鉴。

查询弹层不是新的抽牌页面；卡牌详情直达路由用于普通图鉴和可访问链接，全局查询内部详情用同一展示组件。

详情提供“精简释义 / 完整释义”，与“正位牌义 / 逆位牌义”分别控制。每次打开或刷新默认精简，不记忆上次选择；完整模式依次展示概览、传统牌面象征、当前方向综合解读、感情、工作学业、行动建议，并保留单牌参考链接。长正文在弹层内滚动，关闭按钮保持可见。所有入口使用当前图鉴的完整牌义，旧结果摘要与笔记仍保留快照；当前图鉴找不到卡牌时才回退到快照。

### 首页首屏

保留三张原始牌面，轻微错位倾斜并叠放，中央牌在上层；牌面下方不显示额外牌名和操作提示。移除装饰圆环、标章和重复英文标签，宣传语缩为两行标题与一句说明。桌面两栏居中收紧，三张牌在右侧；手机把三张牌放在文字与按钮上方，依据视口高度缩小牌面和标题，390×844、375×667、320×568 均在底部菜单上方完整展示牌与开始按钮。

三张牌各为独立按钮，支持触摸、鼠标、Enter / 空格。点击后转至背面，等待下一张高清牌面解码后再转回正面；约 760 ms，动画期间当前牌不重复接受点击。每次从完整牌组随机选择，排除当前三张牌，并即时保留新牌占位以避免并发换牌重复。减少动态效果时直接换牌。首页预览不创建会话或历史，不影响当天固定结果。

## 3. 抽牌页面分区

首页四个模式入口以图标、名称与短说明、张数及箭头横向排列，不再分成上下三个区域；桌面卡片约 96 px 高、手机约 92 px 高，手机保留两列。

### 3.1 设置区

模式在设置面板之前以四个可见按钮展示，桌面与手机两列，选中项有暖金边线、背景和勾选标记；按钮通过 aria-pressed 表达状态。自由探索选中后展示 1–10 张数量设置。手机隐藏仅作装饰的牌背区，优先展示控制项。展示数量、牌阵位置、问题输入、逆位开关和概率。概率组件为减号 / 数字 / 加号，关闭逆位时灰化概率组件但保留值。对当前模式明确显示需要几张牌。

操作为“开始洗牌”和“快速抽取”。会话开始后本轮规则固定，设置区收起为摘要。全局声音开关仍可随时调整。选牌摘要提供“更换模式”，确认清除当前未提交选择后才返回设置；取消确认时保留当前牌组。结果页标题区提供“选择抽牌模式”，返回设置不删除历史；再次选择每日一牌仍返回当天固定结果。

### 3.2 洗牌区

洗牌仪式约 3.2 秒，类似扑克牌的 riffle shuffle：整牌分为两叠 → 两侧卡片交错合入 → 牌组拱起回落 → 收拢整齐。洗牌视图退出时记录最上层牌面的真实位置和尺寸，使用同一牌背平滑移动与缩放至圆弧初始牌堆的实测位置，约 620 ms；抵达后才启动逐张摊开，避免视图切换让牌堆跳位。用 24 张共享牌背的视觉卡片表示牌组，不解码 78 张正面。API 准备和动画同时进行，实际随机规则仍是 Fisher–Yates。重新洗牌也完整播放。

“减少动态效果”偏好时用短过渡替代洗牌。快速抽取采用更短过渡，无需重复播放完整仪式动画。

### 3.3 选牌区

全牌组 78 张背面由一叠缓慢摊开成 180° 圆弧，不分页、不分组；同页完整显示，不需要横向滚动。根据容器宽度计算圆弧半径、牌宽、内圆位置与旋转角度，并为两端选中牌留出空间。展开约 3 秒，以逐张延迟的位移和旋转表现扑克牌慢展，期间不接受选牌；恢复已有选择时不重播，减少动态效果时跳过移位与摊牌动画、直接展开。

圆弧下方保留已选顺序、取消与确认操作；确认栏随页面排列，避免覆盖圆弧两端。窗口尺寸变化、查询和刷新均不重新洗牌。

已选区用等宽牌位展示编号、位置名、放大牌背与“放回牌组”，空位保留相同尺寸的占位牌。三张牌在桌面与手机均同排，更多牌桌面最多五列、手机三列自动换行。独立底栏显示选牌进度与提示，桌面右侧放重新洗牌和确认按钮，手机底部并排显示两项操作。确认前只展示背面，不透露牌名与方向。确认成功保存后回到结果页顶部，聚焦结果标题；一般使用平滑滚动，减少动态效果时即时回顶。保存失败时留在当前选牌页，不滚动。

每张背面是可聚焦按钮，点击选中，再点击取消。选中牌向圆弧外侧移出（桌面 36 px，窄屏 18 px）并标注顺序 1…N，再次点击平滑放回；保留原叠放顺序，升起的牌不阻挡邻牌露出的外侧角。数量达到上限时其他未选牌不能再加入，但可取消已选牌。摘要明确显示“已选 X / N”。

“确认选牌”仅在数量正确时可用。打开查询后返回，选牌顺序与滚动位置保持。卡牌沿圆弧重叠，露出的外侧角可点击；手机自动缩小整副牌以保持全牌同时可见。键盘方向键及 Home / End 在牌组中移动焦点，Enter / 空格选中或放回。

### 3.4 翻牌与结果区

每张位置依次展示：位置名 → 卡牌容器 → 中文名 / 英文名 → 正逆位标签 → 关键词 → 基础牌义。三张牌桌面并排，手机也同排。手机多牌展示紧凑牌面、位置名、中文名、正逆位与详情入口，不在每张牌下重复铺开英文、关键词和摘要；完整含义仍通过点牌面或“查看牌义”查看。两张手机两列，三张及更多手机三列，单张保留原来较大的牌面及摘要。多张牌的进度、模式切换和“全部翻开”放在牌组上方，不必滚到底部逐张揭晓。

卡牌采用分开的两个变换：外容器负责 Y 轴翻面；正面图片内层负责逆位 180°。这样翻面动作不会把文字或正逆位变换互相覆盖。已经翻开后点击查看详情，不再把卡牌随机翻回或重新抽牌。

手机精简展示不改变记录、完整牌义和分享图的数据。多牌全部翻开后继续展示牌阵综合解读。

已翻牌数量与已选牌数量分别保存。保存失败时停留明确错误状态，重试不创建新牌。每日已有结果直接进入当天记录，显示“今日已抽取”。

## 4. 素材显示

牌面原尺寸 2538×4208，比例约 0.603。固定正面容器遵循此比例，使用 object-fit: contain；不要裁掉画面内牌名和底部文字。

对称沙漏牌背按约 3:5 竖版比例生成，展示图输出高清 WebP。旧牌背 PNG 与此前设计版本保留存档，不参与当前网站展示或下载清单；正面素材不修改图案及水印。

根据用户最新要求，全站图片统一使用高清展示图：图鉴、查询、详情、历史、翻牌及导出均使用长边 1200 px 的 WebP。图鉴和历史列表仍按视口懒加载；选牌阶段共享高清牌背，不解码全部正面。

新记录保存高清牌面 Blob，在展示资源失效时提供同分辨率本地回退，PNG 导出也保持高清来源。旧记录的缩略图字段保留兼容，不作为显示来源；完整离线包含全部高清展示图。

## 5. 查询弹层

桌面使用居中的查询面板，手机使用全屏面板或底部抽屉。内容为搜索输入、分类筛选、结果数、卡牌缩略列表。查询结果可打开详情，详情关闭回到原搜索词和列表滚动位置。

详情提供正位 / 逆位牌义标签切换，不改变当前抽牌记录。搜索与卡牌字段仍能在离线使用；只有本地数据未下载时显示需要联网或下载的提示。

打开时聚焦搜索框，Escape 关闭，关闭后焦点回到触发按钮。背景内容不接受点击或键盘焦点，页面滚动不丢失。移动端返回键优先关闭当前查询详情 / 查询面板，不直接销毁抽牌会话。

## 6. 音频设计

页面保持一个背景音乐实例，由全局控制器管理。背景音乐和音效分别开关，提供合理音量；不随路由切换叠加播放。背景音乐较低，音效短且柔和。

背景音乐源为用户提供的 `assets/sounds.mp4`，约 354.73 秒。Mac 素材脚本使用 afconvert 复制 AAC 包为 M4A，不重新编码，原 MP4 保留；已生成资源可跨平台复用，无转换工具时直接发布 MP4 音轨。HTMLAudioElement 开启 loop，资源纳入音频下载与 SHA-256 校验，切换页面不创建新播放器；关闭音乐即暂停，重新开启继续播放。

设计默认音频开关开启，但浏览器可能阻止自动播放。用户首次点击洗牌、选牌或显式声音按钮时尝试解锁；失败显示“点击播放音乐”，不把播放失败当成抽牌失败。[浏览器自动播放说明](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay)

洗牌开始播放一次洗牌音效；每张首次揭示时播放一次翻牌音效。音效关闭后立即停止残留声音。浏览器后台、设备静音、资源未缓存时应有合理降级。

## 7. 历史与分享

历史列表展示模式、时间、牌面缩略和问题摘要。详情展示所有位置、方向、当时牌义快照和笔记编辑区。删除单条需简短确认；清空历史明确范围，保留当天每日结果。

分享图宽度 1200 px，采用中世纪油画画布、古金花叶边饰、暖色衬线文字和装裱牌面。可选择古金棕或勃艮第红色调，以及最多三列的卡牌画廊或单列手稿长卷；不足一行的牌居中。背景位于 `frontend/src/export/assets/medieval-oil-v1.png`，随 Vite 资源发布并缓存到离线应用壳。

内容组件包括卡牌画廊、核心牌义、牌位解读、牌阵综合解读、行动建议、问题和笔记，可逐项勾选、通过上下箭头排序。标题和落款可自定义，日期、牌位标签及金线边框可开关；默认只包含卡牌与核心牌义，每次打开均重置问题和笔记为关闭。笔记按 Unicode 字符截取最多 700 字，空内容及单张牌的综合解读不可选。

Canvas 按字体测量段落、标题及换行后分配高度，保持模块间距，图片和文字独立渲染，原始牌面和正逆位不修改。修改选项会清除旧预览和下载链接，重新生成后才能下载；高度超过 13000 px 时提示减少组件。关闭弹窗及更换预览会释放 Blob URL。

导出前提供预览及个人内容勾选。字体和媒体同域，等待图片解码和字体就绪后渲染；导出期间按钮禁用防止并发。图片过大、字体失败时显示重试或基础字体回退。

## 8. 资源与错误状态

| 状态 | 界面呈现 |
|---|---|
| 正在创建会话 | 准备提示、禁用重复开始 |
| API 不可达，本地包可用 | 简短离线状态标记，继续同一操作 |
| 无网且包未准备 | 提示联网下载，保留已输入问题 |
| 下载一部分失败 | 显示进度与失败数量，可重试 |
| 核心 ready、音频未 ready | 可以离线抽牌，显示音频未下载 |
| 本地保存失败 | 提示未保存，保留内存状态与重试按钮 |
| 搜索无结果 | 显示条件与清除筛选按钮 |
| 卡牌图片缺失 | 名称与牌义仍可读，提供修复下载 |
| 应用有新版本 | 空闲时提示更新，当前抽牌不强制刷新 |

## 9. 可访问性与适配

桌面目标布局为 1280–1440 px，手机重点验证 375–430 px，并兼容窄屏 320 px。关键按钮可用键盘；卡牌背面使用“第 N 个牌位，已选 / 未选”的标签，不提前用隐藏牌名泄露选择状态。

翻开后朗读位置、牌名和方向。文字不依赖图像内英文标题；颜色、声音或动画不作为唯一状态提示。减少动态效果时仍能完整抽牌和查看结果。

纸纹、卡牌素材与中文字体以实际浏览器视觉检查为准，开发中至少完成手机触控、桌面键盘、查询开关及自由抽取 10 张四类页面验证。

## 多张牌综合解读

所有牌翻开后，在单牌网格与分享操作之间展示独立纸张区块「牌阵综合解读」，用三个段落呈现整体脉络、牌与牌的联系和行动建议。桌面限制正文宽度，手机纵向阅读并保留清晰段间距。单张牌或尚未全部翻开时隐藏整个区块；三张牌阵采用对应牌位，自由抽取不赋予虚构的位置。复用同一 ReadingView 支持历史详情，刷新及离线重新打开后可恢复。单牌点击仍默认精简释义。
