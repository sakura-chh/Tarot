# 塔罗抽牌网站项目文档

版本：1.5｜日期：2026-10-01（Asia/Shanghai）｜阶段：第一版本地应用

本套文档根据用户逐项回答编写。第一版本地应用现已建立，运行方式见根目录 [README.md](../README.md)。网站尚未部署到公网，中文牌义已整理为草稿，等待用户审核。02、03、08 描述当前代码与验证状态；早期需求、验收目标及未来 AI 设想不代表全部已实现。

Agent 工作入口为根目录 [agent.md](../agent.md)，包含七类开发约定、实际命令和持续更新规则，保持约 200 行。

## 一、项目定位

制作一个自己和朋友使用的塔罗网页：在手机和电脑上完成洗牌、手动选牌、逐张翻牌、中文牌义查看、全站卡牌查询和记录。视觉采用星空背景、通透玻璃导航与复古衬线字体，保留现有牌面。网站支持下载资源后的离线使用，各设备分别保存记录，无需账号。

最终架构为 **Python / FastAPI 后端 + React / TypeScript / Vite 前端 + SQLite 公共卡牌数据库 + IndexedDB 个人本地数据 + PWA 离线缓存**。Python 是主要后端语言；浏览器仍需要 JavaScript / TypeScript 完成动画、音频和离线抽牌。

## 三、已确认的需求摘要

| 项目 | 已确认选择 |
|---|---|
| 使用环境 | 手机和电脑浏览器 |
| 使用人群 | 自己和朋友 |
| 牌组 | 素材包内完整 78 张牌面；深紫底粉金对称沙漏牌背 |
| 模式 | 每日一牌、两种三张牌阵、自由抽取 1–10 张 |
| 两种牌阵 | 过去 / 现在 / 未来；现状 / 阻碍 / 建议 |
| 手动流程 | 扑克牌式分堆、交错、收拢 → 全部 78 张选牌 → 确认 → 翻牌 |
| 快速模式 | 自动选择当前洗好牌组的前 N 张，支持逐张翻牌 |
| 每日一牌 | 当前设备当天首次确认抽取后固定 |
| 逆位 | 可关闭；开启时默认 50%，允许通过按钮调整 |
| 风格 | 近黑星空、闪烁星点与流星、通透玻璃导航、0.96 按压与阻尼回弹，保留复古牌面 |
| 声音 | 背景音乐及洗牌、翻牌音效，分别开关并调节 0–100% 音量；首页翻牌同样有音效 |
| 牌义 | 参考神婆网整理 78 张中文正逆位释义；图鉴可切换精简 / 完整，后续由用户审核 |
| 卡牌查询 | 全站入口、中文 / 英文名称 / 关键词搜索、分类筛选、详情、图鉴 |
| 记录分享 | 本地历史、问题与笔记；油画风 PNG，七种内容组件可勾选、排序，个人内容默认关闭 |
| 离线 | 资源包完整下载后可离线使用 |
| 同步与账号 | 无账号，无跨设备自动同步 |
| 前端 | React + TypeScript + Vite |
| 后端 | Python；架构采用 FastAPI |
| AI | 后续版本扩展，第一版只提供固定牌义 |

## 四、设计约定与未完成事项

需求选择是已确认事实；本文中的颜色、尺寸、概率步长、接口形状、性能预算和任务安排属于可执行设计约定，可在开发前后根据验证结果调整。

- 概率范围采用 0–100% 整数，按钮每次调整 5 个百分点，支持直接输入。
- 每日一牌默认按设备当地日期判断，不按服务器 UTC 日期判断；跨设备结果可以不同。
- 音频开关默认开启，首次用户交互后尝试播放；播放失败提供显式播放按钮。
- 个人问题、笔记和历史不上传服务器。后端只临时保存匿名抽牌会话以处理重试。
- 中文牌义含 156 段精简摘要与 78 张牌的完整分主题正文，参考来源逐牌记录；背景音乐采用用户提供的 sounds.mp4 音轨并循环，两种音效由脚本合成。
- 新牌背由内置 image_gen 工具制作；源图和提示词记录在 `design/`。原牌背保留存档。
- SQLite 与 IndexedDB 使用第一版简化结构，详见数据文档的实现说明。
- 按用户要求使用现有素材。素材来源与授权凭证尚未由本地文件证实；此项只是资料状态记录，不把“使用现有素材”的指示解释为已核验授权。
- 没有确认发布时间或预算，本套文档给出阶段和验收条件，不承诺日期。

## 五、GitHub 调研结论

优先借鉴 Python 插件的配置化卡牌模型、PWA 项目的每日结果复用、React 项目的本地记录组织、REST API 项目的查询接口。将这些思路用于本项目自己的架构。没有发现一个已核查仓库同时符合完整 78 张指定素材、复古风格、React、Python 后端、离线抽牌及设备独立记录的全部要求。

具体文件、核查版本、许可证与取舍见 [GitHub 借鉴分析](06-github-references.md)。本次没有复制任何参考仓库代码或牌义内容。
