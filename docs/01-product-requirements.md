# 产品需求说明

版本：1.1｜日期：2026-10-01｜状态：已确认需求与实施约定

## 1. 目标与范围

为个人和朋友提供有仪式感、操作清晰的塔罗抽牌工具。核心体验是用户自己选牌和翻牌，查看对应的中文牌义，并留下问题与笔记。全站可以查询卡牌。完成资源下载后，主要功能可以离线使用。

第一版包含全部已确认功能；第一版后扩展 AI。账号体系、跨设备同步、付费、商城、公众运营后台、拖拽切牌、复杂自定义牌阵未纳入第一版。自由抽取允许 1–10 张及个人笔记，不等同于自定义空间布局编辑器。

## 2. 使用场景

| 场景 | 操作 | 结果 |
|---|---|---|
| 每天自我反思 | 打开每日一牌，首次选牌 | 得到当天固定的一张牌及对应正逆位牌义 |
| 梳理一件事 | 选择一种三张牌阵并填写问题 | 按选牌顺序对应三个位置，逐张查看牌义 |
| 自由抽取 | 选择 1–10 张 | 得到不重复的牌，按第 1 张至第 N 张排列 |
| 快速抽取 | 设置模式与逆位概率后点击快速抽取 | 直接进入待翻牌状态，不经过手动选牌 |
| 查询卡牌 | 在任一页面打开查询 | 可搜索名称、关键词并看详情；返回后抽牌状态保留 |
| 记录与分享 | 完成抽牌并填写笔记 | 本地保存记录；可生成一张分享图 |
| 离线使用 | 先下载离线资源，再断网 | 继续查询、抽牌、写笔记、查看历史和导出图片 |

## 3. 功能规格

### F01 全局导航与首页

全站采用近黑底色、闪烁星点与间歇流星的星空背景，顶部悬浮导航与手机底部浮岛具有通透玻璃质感，高光胶囊随菜单平滑移动。按钮按压缩放至 0.96 并增加内阴影，松开连续阻尼回弹，键盘可用且尊重减少动态效果。提供首页、抽牌、卡牌图鉴、历史、设置五个入口。每个页面都提供卡牌查询入口。首页三张牌自然叠放，牌下不显示牌名和操作提示，可独立翻转换成随机新牌，排除当前三张牌；预览不生成历史。手机先展示三张牌，再展示紧凑的宣传语和探索按钮，均位于首屏及底部菜单上方；桌面两栏收紧。下方提供紧凑的四种模式入口，当前音频开关保留于顶栏。

抽牌设置页以四个明确按钮展示全部模式，选中项有高亮与勾选。选牌中可确认更换模式，取消时保留进度；结果页也提供返回模式选择的入口，不删除历史或当天固定结果。

### F02 完整牌组

使用提供的 78 张牌面：22 张大阿尔卡那，四个花色各 14 张小阿尔卡那。任何抽牌模式均使用完整牌组。正面保留原始图案及水印。根据用户最新参考图，背面采用深紫底、粉金线描的对称沙漏、水晶与植物纹样，不使用太阳、月亮或月相；原背面保留存档。

图片文件前缀不作为业务 ID。采用名称稳定 ID，花色和牌阶单独建模。原文件的正义为 8、力量为 11，展示编号遵循该素材；牌义匹配依据卡牌名称，不从其他项目的整数位置直接拷贝。

### F03 每日一牌

1. 当天是否已有结果以浏览器 IndexedDB 中的每日索引为准。
2. 首次选牌确认时，在一个事务中保存结果、历史和每日索引，再允许翻牌。
3. 再次进入直接显示相同牌及方向，不创建新抽牌会话。
4. 关闭页面、刷新、修改逆位设置、切换网络、删除普通历史均不会改变当天结果。
5. 日期采用设备当地日期，并保存当时的时区及 UTC 时间；页面在午夜后或重新获得焦点时重新检查日期。
6. 每个设备、浏览器配置和网站源分别保存；清除全部站点数据后无法保证当天结果恢复，不宣称服务器级强制限制。
7. 删除历史不删除当天每日索引。设置中的“清空本地数据”须明确说明会同时清除每日结果。

设计采用 `deck_id + local_date` 唯一键，不将逆位概率或数据版本加入每日键，以免调整设置、发布牌义时重新抽出当天牌。

### F04 三张牌阵与自由抽取

| 模式 ID | 数量 | 位置顺序 |
|---|---:|---|
| daily | 1 | 今日提示 |
| past_present_future | 3 | 过去、现在、未来 |
| situation_obstacle_advice | 3 | 现状、阻碍、建议 |
| free | 1–10 | 第 1 张、第 2 张…… |

两种三张牌阵分开选择。按用户选牌的先后顺序放入位置，而非按原始牌号、文件顺序、屏幕位置排序。一次会话内不重复；不同会话间允许抽到相同牌。

多张牌（2–10 张）全部翻开后，自动在结果下方独立展示「牌阵综合解读」，包含整体脉络、牌与牌的联系、可以尝试的一步。三张模式按过去 / 现在 / 未来或现状 / 阻碍 / 建议解释，自由抽取按共同主题并读，不额外假设时间或因果牌位。使用实际正逆位，逆位不一律视为负面；未翻完时不泄露未揭晓的牌。历史与离线均可查看，单张牌不显示此区块。第一版由本地牌义主题与牌阵规则整理，不调用 AI 或上传问题与笔记。

### F05 手动选牌与快速抽取

手动：设置模式 → 可选问题 → 扑克牌式分堆、交错、收拢洗牌 → 一叠牌缓慢摊成 78 张圆弧 → 点击选牌，选中的牌升起 → 确认 → 翻牌。整副牌不分页、不分组，78 张背面在同页完整形成半圆弧；按容器宽度缩放，不需要横向滚动或浏览箭头。选中显示顺序，再次点击可放回；确认后固定牌及方向。展开动画约 3 秒，结束后开放选择；恢复已有选择和减少动态效果时直接显示展开状态。键盘支持方向键及 Home / End 浏览、Enter / 空格选牌。

快速：创建相同规则的洗牌会话，取牌组前 N 张作为选择结果并保存，进入逐张翻牌。不通过反复调用随机接口拼接结果。

在未确认前重新洗牌会创建新会话并清空选牌。已确认后“再次抽牌”适用于三张牌阵和自由模式；每日一牌当天没有重抽入口。

### F06 正位与逆位

提供独立逆位开关。开启默认概率 50%，范围 0–100% 整数。通过减号 / 加号每次调整 5 个百分点，也支持直接输入；边界按钮禁用。

关闭逆位时所有牌为正位，保留之前设置的概率供再次开启时使用。开启时每张牌方向独立生成，50% 表示每张的概率，不承诺一组牌恰好一半为逆位。

概率和开关在创建抽牌会话时形成快照。本轮洗牌后设置锁定；想改变本轮规则需要重新开始。全局修改只影响下一轮。方向只生成一次，不在翻牌、查询、重绘或查看历史时重新随机。

### F07 翻牌与固定牌义

逐张点击翻开。方向影响牌面旋转和展示的牌义；牌名、位置标签和正文仍保持正常阅读方向。翻牌后允许打开详情。可提供“全部翻开”便利按钮，默认流程仍为逐张。

每张牌包括中文名、英文名、所属类别、花色或编号、关键词、正位基础牌义、逆位基础牌义。固定牌义不因问题动态改变；问题用于个人记录，AI 后续才做结合问题的解释。

根据用户补充要求，78 张牌义参考 [神婆网牌意](https://www.shenpowang.com/taluopai/jieshi/)重新整理。抽牌结果、历史、图鉴 / 查询详情均可选择精简摘要或完整分主题释义；完整内容包含概览、牌面象征、正逆位综合解读、感情、工作学业、行动建议和单牌来源。详细程度与牌面方向独立，每次打开默认精简，不记忆上次阅读模式。旧记录的详情按卡牌 ID 查询当前完整牌义，不改写抽牌快照与笔记。

由项目作者整理中文基础牌义，不逐字搬运参考仓库或外部文章；每张牌有内容审核状态。第一版发布前完成 78 张正逆位文字审核。不要从正义 / 力量的不同编号规则推断整套牌与某个传统体系完全一致。

### F08 全站卡牌查询与图鉴

- 每个页面可用全局入口；桌面显示搜索按钮，手机提供明显触达入口。
- 支持中文名、别名、英文名、关键词及牌义文字检索。
- 可组合筛选大 / 小阿尔卡那、宝剑 / 权杖 / 星币 / 圣杯。
- 图鉴初始显示全部 78 张，支持筛选和搜索；查询弹层默认展示常用入口或全牌列表。
- 详情包括完整牌面、名称、类别、关键词及两种牌义；正逆位切换只改变查询展示，不改变当前抽牌结果。
- 空查询返回全牌；无结果显示提示并允许清除条件；输入更新可采用 150–250 ms 防抖。
- 全局查询打开时暂停页面交互但保存抽牌会话、已选牌及已翻牌状态；关闭后恢复焦点。
- 离线查询使用已缓存的完整数据，结果排序与在线接口一致。

检索契约详见数据文档：关键词与分类条件相交，多个关键词也按相交处理。78 张规模无需向量数据库或独立搜索服务。

### F09 历史、问题和笔记

抽牌确认后自动保存记录，已翻牌集合同步保存，避免刷新后丢失。记录包含模式、问题、位置、卡牌、方向、概率设置、时间、数据版本和笔记。

历史按时间倒序；支持按模式筛选、查看详情、编辑笔记、删除单条、清空历史。默认不自动裁掉最近 10 条之外的记录；存储不足显示失败原因，不静默删除。

问题可留空，设计长度上限 500 字；笔记上限 5,000 字。保存状态有明确反馈。内容按纯文本显示，不执行用户输入的 HTML。

### F10 分享图

在浏览器生成 PNG。包含牌面、模式 / 位置、正逆位标签、抽牌日期及简洁装饰。默认不附个人问题和笔记；导出前可选择加入问题，笔记由用户主动选择。

自由抽取较多时使用多行布局或长图，保持牌名可读。下载图片是第一版必须能力；系统分享面板是浏览器支持时的增强能力。生成图片不上传服务器，取消导出不产生额外记录。

### F11 音乐与音效

背景音乐采用用户提供的 `assets/sounds.mp4` 音轨，循环播放；提供洗牌、翻牌两种音效。背景音乐和音效分别开关，并保存到本设备。设计默认开关开启，但实际播放等待浏览器允许的首次用户交互；被阻止时显示播放按钮。

每个已翻开的卡牌只触发一次翻牌音效。关闭开关即时停止对应声音。切换页面不重复创建背景音乐实例；页面进入后台默认暂停背景音乐，返回时根据用户设置恢复。

当前素材包没有音频，实施阶段补充来源明确、可使用的音乐和音效。没有音频时界面核心功能仍可验收，完整发布验收要求音频到位。

### F12 离线包与本地数据管理

设置页提供下载离线资源、进度、已下载大小、可用状态、重试、清除离线资源。核心离线包包含页面、78 张展示牌面、缩略图、牌背、牌义和牌阵；音频可随完整资源包下载，并单独显示状态。

核心包所有必需资源校验完成后才标记“可离线使用”；音频缺失标记“离线音频未就绪”，不把图片包失败误报为完成。初次访问尚未下载不能承诺离线可用。

清除离线资源保留历史和笔记。清空个人数据保留离线资源。清空全部分别提示影响范围。浏览器本地数据可能被用户或浏览器清除，界面给出设备保存位置说明，不承诺永久保存。

## 4. 第一版完成标准

所有 F01–F12 功能有可操作入口；既定 78 张牌无缺失、误映射、重复；每日固定与抽牌方向可恢复；查询不打断会话；离线包完成后断网可走通核心流程；问题笔记留在设备；桌面与手机布局可用。

逐条验收案例见 [开发与验收](05-delivery-and-acceptance.md)。
