# 第一版实现与验证

日期：2026-09-30｜应用 0.1.0｜数据 2026.09.30.4

本地网址：http://127.0.0.1:8000。启动入口为根目录 `start.command`，操作说明见 [README](../README.md)。尚未部署公网。

## 已完成

- Python / FastAPI + SQLite 在线抽牌与公共数据；React / TypeScript 响应式网页。
- 每日一牌、两种三张牌阵、自由 1–10 张；快速抽取和手动选牌。
- 深紫底粉金对称沙漏牌背，无太阳或月亮；分堆、交错合牌、拱起收拢的扑克牌式洗牌动画。
- 同时展示全部 78 张可选牌；手机纵向滚动，底部保留确认与取消操作。
- 全站使用长边 1200 px 高清 WebP：首页、图鉴、查询、详情、历史、翻牌与 PNG 导出。
- 新历史记录保存高清图片 Blob；不再用 340 px 缩略图作为显示或导出来源。
- 当天固定结果、概率快照、查询后恢复、本地历史与笔记、独立声音开关。
- 校验后的离线资源、暂停与修复、空间提示；应用壳按构建版本缓存，首页主动更新。

## 内容与发布状态

78 张正逆位牌义和关键词已整理为草稿，仍需逐张审核。背景音乐、洗牌与翻牌音效由素材脚本原创合成；牌背由内置 image_gen 生成，源图和提示词见 [设计记录](../design/README.md)。

资源清单含 163 项，总计 28,806,760 字节。原始 `assets/` 79 个文件保留，旧牌背不参与当前展示。没有复制参考 GitHub 项目的代码或牌义。

第一版使用简化存储结构，不含账号、AI、跨设备同步和公网部署。后端目前提供当前数据版本；旧图片保留，历史文本与新记录高清快照独立保存。
