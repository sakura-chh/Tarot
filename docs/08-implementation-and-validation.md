# 当前实现与验证

版本：1.2｜日期：2026-10-01｜应用 0.1.0｜数据 2026.10.01.1

本地网址：http://127.0.0.1:8000。Mac 入口为根目录 `start.command`；安装与命令见 [README](../README.md)。尚未部署公网。本文汇总当前实现，不将早期设计或历史测试次数当作本次新验证。

## 已实现的功能

| 部分 | 当前行为 |
|---|---|
| 首页 | 三张宣传牌独立翻转、随机换图并播放音效；不创建记录。探索按钮采用深色玻璃、浅金文字和细描边 |
| 视觉与选择器 | 近黑星空、闪烁星点、流星、玻璃导航；类别、花色、历史模式、数量及分享选项共用顶层下拉菜单，与触发框等宽对齐，支持键盘 |
| 抽牌 | 每日一牌、时间之流、内在指引、自由 1–10 张；手动或快速；完整 78 张圆弧，选中升起并标记顺序 |
| 选牌界面 | 顶部更换模式和重新抽牌；圆弧适应剩余视口。已选牌直接展示高清牌背，无外框，点击放回原 slot |
| 结果界面 | 确认保存后回顶并聚焦标题；1–10 张紧凑首屏翻牌区，手机 7–10 张五列两行；进度与全部翻开在上方 |
| 牌义与解读 | 每张已翻牌提供核心牌义、牌位作用、行动和问题；可展开象征、关系与工作。多张全部翻开后提供综合解读，未翻牌不提前泄露 |
| 详情与查询 | 当前完整 78 张数据本地搜索；搜索、牌义均为玻璃弹窗。桌面详情左图与标题固定，右侧独立滚动；手机上下布局 |
| 记录 | 当天结果固定，多标签页事务防重复；方向和概率为本轮快照。历史、问题、笔记仅保存在当前浏览器 |
| 分享 | 中世纪油画背景与古金边饰，1200 px PNG；卡牌、牌义、牌位、综合解读、行动、问题、笔记七种组件可勾选和排序；两种色调与排布、标题和落款可调整，个人内容默认关闭 |
| 高清素材 | 全站使用长边 1200 px WebP，新记录保存可选高清 Blob；历史和导出可在网络素材失败时回退 |
| 音频 | 用户提供音轨循环播放，洗牌和翻牌音效；分别开关、调节 0–100% 音量。旧设置补齐音乐 28%、音效 55%，跨页面共用一个播放器 |
| 离线 | 正式构建注册 Service Worker；清单与资源长度、SHA-256、版本校验，暂停、续传和修复，媒体与应用壳隔离，缓存音频支持 Range |
| 接口保护 | 本机 Host、同源来源检查、严格 JSON、4 KiB 请求体和 5 秒接收超时；读 240 / 写 30 次每分钟每 IP，活跃会话上限 10000；CSP 与安全头，默认关闭 API 文档 |
