# 第一版实现与验证

日期：2026-10-01｜应用 0.1.0｜数据 2026.10.01.1

本地网址：http://127.0.0.1:8000。启动入口为根目录 `start.command`，操作说明见 [README](../README.md)。尚未部署公网。

## 已完成

- Python / FastAPI + SQLite 在线抽牌与公共数据；React / TypeScript 响应式网页。
- 全站近黑星空、260 个淡出消失后随机换位的闪烁星点与间歇流星、通透玻璃悬浮导航与手机底部浮岛；滑动高光胶囊、0.96 按压、深度内阴影与连续阻尼回弹。
- 首页三张牌自然叠放，移除牌下额外名称及提示，可独立翻转换成随机新牌，排除当前牌；手机三张牌在缩小宣传语与探索按钮上方，桌面两栏收紧；预览不改变每日结果或创建记录。
- 用户提供的 sounds.mp4 音轨无损提取为约 5 分 55 秒的 M4A，循环播放、独立开关、跨页面单实例并加入离线清单。
- 每日一牌、两种三张牌阵、自由 1–10 张；快速抽取和手动选牌。
- 深紫底粉金对称沙漏牌背，无太阳或月亮；分堆、交错合牌、拱起收拢的扑克牌式洗牌动画；收好的牌堆以 620 ms 实测位置与尺寸过渡至摊牌起点，抵达后才展开。
- 78 张可选牌从一叠缓慢摊成圆弧，同页完整展示；按屏幕宽度缩放，选中向外侧升起并显示顺序，底部保留确认与取消操作。
- 已选区采用放大的等宽牌位，显示位置、顺序与放回操作；三张牌手机同排，更多牌自动换行；进度和确认操作放入独立底栏。
- 全站使用长边 1200 px 高清 WebP：首页、图鉴、查询、详情、历史、翻牌与 PNG 导出。
- 新历史记录保存高清图片 Blob；不再用 340 px 缩略图作为显示或导出来源。
- 确认保存成功后回到结果顶部并聚焦标题，查看/关闭牌义与笔记更新不重复回顶；手机多牌紧凑网格，三张同排、更多三列，进度与全部翻开放在牌组之前，详细内容通过点击牌面查看。
- 当天固定结果、概率快照、查询后恢复、本地历史与笔记、独立声音开关。
- 校验后的离线资源、暂停与修复、空间提示；应用壳按构建版本缓存，首页主动更新。
- 多张牌全部翻开后独立展示牌阵综合解读，包含整体脉络、共同主题与行动建议；本地整理，历史与离线均可用。
- 78 张牌义参考神婆网逐张重新整理；抽牌结果 / 历史 / 图鉴 / 查询详情统一读取当前完整释义，支持精简与完整模式、分主题正逆位及原文链接。每次打开默认精简，原抽牌快照与笔记保留。弹层采用半透明毛玻璃、边缘高光及牌面相框，固定关闭栏，并有减少透明度/增强对比度回退。

## 内容与发布状态

78 张正逆位摘要、关键词与完整分主题正文已参考神婆网重新整理，仍可继续逐张审核；来源和对应规则见 [牌义说明](09-meaning-sources.md)。背景音乐采用用户提供的 assets/sounds.mp4 音轨，Mac 使用 afconvert 复制 AAC 包为 M4A；洗牌与翻牌音效由脚本合成；牌背由内置 image_gen 生成，源图和提示词见 [设计记录](../design/README.md)。

资源清单含 163 项，总计 30,658,736 字节。原始 `assets/` 79 张图片与新 sounds.mp4 均保留，旧牌背不参与当前展示。没有复制参考 GitHub 项目的代码或牌义。

第一版使用简化存储结构，不含账号、AI、跨设备同步和公网部署。后端目前提供当前数据版本；旧图片保留，历史文本与新记录高清快照独立保存。
